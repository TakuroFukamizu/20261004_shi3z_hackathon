# H3 ゲーム ― 熱血高校の一日

DOF Reality **H3**(3軸モーションプラットフォーム)に座って遊ぶ、声とレバーで進む 3 シーンのゲーム。
2026-10-04 のハッカソンで作った。別の PC と手元の LLM サーバーで動かす手順は [INSTALL.md](INSTALL.md)。

```
ブラウザ(web/)  ──HTTP 30回/秒──▶  bridge.py  ──USB シリアル──▶  H3 の制御ボックス
   │                                  │
   │ 音声認識(Chrome → Google)          ├── joy_reader.py(スティック・ペダルを pygame で読む)
   │                                  └── /ai → OpenAI 互換の LLM サーバー(文字だけ)
   └── マイク(getUserMedia)
```

## 遊び方

1. `./start.command`(Mac)または `start.bat`(Windows)でブリッジを起動する。
2. **Chrome** で http://localhost:8891 を開く。
3. 確認画面で、席・スティック 2 本・ペダル・マイクが見えているかを確かめ、**スタート**。

| シーン | 場面 | やること | 席の動き |
|---|---|---|---|
| 1 校門 | 生徒指導の先生 | 両レバーを手前いっぱいに引いて気合いを溜め、マイクに「おはよう」と叫ぶ。声の大きさが **HP**、気合いが **MP** になる | 溜めるほどのけぞって震える。声で震える |
| 2 教室 | 地震 | 「おかしもち」(押さない・駆けない・しゃべらない・戻らない・近寄らない)を 20 秒以内に声で答える。言えなかった分だけ HP が減る | 地震。言えるほど弱まり、外すと突き上げる |
| 3 帰り道 | 先生たちと校長先生 | 一人称で走りながらスティック左右でよける。トリガーで気合いバリア(MP 20)。家に着いたらお母さんに「ただいま」 | よける向きに傾く。ぶつかると衝撃 |

- どのシーンもチャイムで始まる。鳴っている間はマイクを使わない。
- 機器が無くてもキーボードで動く: 矢印/WASD = スティック1、Q/E = ペダル、スペース = トリガー、`1`〜`5` = 音声の代わり。
- `Esc` で確認画面に戻る。`http://localhost:8891/?scene=quake` のように付けると、そのシーンから始まる(`gate` / `quake` / `boss`)。

## 判定の仕組み

音声を直接読める AI は使っていない。役割を分けている。

| 何を | どうやって |
|---|---|
| 言葉(「おはよう」「おかしもち」「ただいま」) | Chrome の音声認識(Web Speech API)で文字にし、キーワードで照合 |
| 声の大きさ・長さ | ブラウザでマイクの音量を実測(自動音量調整は切ってある) |
| 感情・気合い・先生の一言(シーン 1) | 認識した文字と実測値を LLM(OpenAI 互換 API)に渡して JSON で受け取る。気合いは実測と半々に混ぜる |

LLM に届かないときは「AI なし」と表示して実測だけで進む。音声認識が使えないときはキーボードで代用できる。

## ファイル

| ファイル | 役割 |
|---|---|
| `bridge.py` | ブリッジサーバー(ポート 8891)。画面の配信、席への送信、`/ai`、`/pads`、`/state` |
| `h3_direct.py` | H3 の制御ボックスとシリアルで話す(SMC3 互換、500000 baud) |
| `joy_reader.py` | スティック・ペダルを pygame で読む子プロセス |
| `web/index.html` | 土台。確認画面、入力のまとめ、席への送信、シーンの呼び出し |
| `web/input.js` | スティック・ペダルの役割割り当て(キットのもの) |
| `web/mic.js` / `web/speech.js` | マイクの音量・録音 / 音声認識 |
| `web/game.js` | シーン切り替え、HP/MP、チャイム、効果音 |
| `web/scene1_gate.js` `scene2_quake.js` `scene3_boss.js` | 各シーン |
| `web/chime.mp3` | 効果音ラボ「学校のチャイム」の冒頭 6.5 秒 |

## 設定(環境変数)

| 変数 | 既定 | 意味 |
|---|---|---|
| `H3_LLM_URL` | `http://192.168.100.143:8080/v1/chat/completions` | LLM の OpenAI 互換エンドポイント |
| `H3_LLM_MODEL` | (なし) | Ollama のようにモデル名が要るサーバーで指定 |
| `H3_PORT` | `8891` | ブリッジのポート |
| `H3_DRY` | (なし) | `1` で席に何も送らない(画面だけ試す) |
| `GEMINI_API_KEY` または `~/.gemini_env` | (なし) | あれば録音ごと Gemini に渡す(キットの仕組み) |

画面側の設定(揺れの大きさ、向きの反転)は確認画面で変え、ブラウザに保存される。

## 安全

- 揺れの大きさは 0.35 から。人を乗せる前に空の席で試す。上限は 0.6 にしてある。
- 画面からの信号が止まると席はゆっくり中央に戻る。待機中の自動揺れは切ってある。
- 記事(shi3z, note)にある通り、体重と勢いで倒れることがある。シーン 2 の地震は強めなので、最初は揺れの大きさを下げて試す。

## 新しいシーンを足すには

`web/scene_xxx.js` に次の形で登録し、`index.html` で読み込む。

```js
Game.scenes.xxx = {
  enter() {},                         // シーン開始時
  update(dt, inp) {                   // inp.x, inp.y, inp.rudder, inp.fire, inp.keys ...
    return {pitch: 0, roll: 0, yaw: 0, smooth: 0.12};   // 席の動き -1..1
  },
  draw(x, W, H) {},                   // canvas
};
```

`Game.go('xxx')` で切り替え、`Game.status`(hp, hpMax, mp, mpMax)を持ち回る。`Game.text` / `Game.gauge` / `Game.sfx` / `Game.chiming()` が使える。
